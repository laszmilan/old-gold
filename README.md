# Old Gold

The website for **Old Gold**, a fantasy adventure game of daring exploration, creative problem-solving, and fast-paced tactical combat, with OSR roots and modern design.

One page per language: the cover fills the first screen, the whole rulebook follows under it. Free to read online.

[oldgoldrpg.com](https://oldgoldrpg.com) · published by [Tiny Raven Press](https://tinyravenpress.itch.io/old-gold/)

## Editing the rules

Edit `content/old-gold-en.md`, then:

```
node build.js
```

That rewrites `index.html`, `hu/index.html`, `rulebook.html`, `404.html` and `sitemap.xml`. Commit them with your text changes. Editing the Markdown on GitHub instead, a workflow rebuilds and commits for you.

The pages hold the rules as plain HTML, so they work without JavaScript and without a server: open `index.html` to preview.

`content/old-gold-hu.md` is the Hungarian translation, still partial.

## Layout

| | |
|---|---|
| `content/` | the rulebook, in Markdown |
| `build.js` | renders the Markdown and writes every page |
| `config.js` | Discord, itch.io and email links |
| `assets/css/styles.css` | the design |
| `assets/css/fonts.css` | generated by `tools/fetch-fonts.js` |
| `assets/fonts/` | the two typefaces, self-hosted |
| `assets/js/site.js` | contents dialog, reading position, language switch |
| `tools/` | font fetcher, responsiveness audit |

Generated, don't edit: `index.html`, `hu/index.html`, `rulebook.html`, `404.html`, `sitemap.xml`.
